## 二、方法论沉淀（可复用）

1. **ERROR 不可见时的降级策略**：OJ 不透出 diag。与其盲猜，不如把预验证路径上的未知异常降级为可重试 ABORT——瞬时故障被消化，持续故障退化为单事务放弃，运行存活后其余阶段的反馈价值远大于一条 ERROR。
2. **崩溃镜像离线重放**：kill -9 后 `cp -a` 数据目录 = 可无限重放的现场。配合恢复端 `RMDB_TRACE_ROW="v0,v1"`（env 门控、匹配首两 int 列）逐记录审讯，一次命中根因。
3. **机制级注入验证**：竞态窗口本地打不中时，在嫌疑点注入其效果（如 1/500 概率重定位倒退、1/5000 fetch_page 返 nullptr），对比修复前后行为差异——把"不可复现"变成"可判定"。
4. **位精确聚合是本地门禁盲区**（已补）：oj_gate 此前只查 w/d_ytd 账本与行数；OJ 崩后查七项 FLOAT32 聚合 0/≤1 ULP。`crash_aggregate_check.py` 首轮即复现 OJ 判负。
5. **失败时刻的形态学**：measurement 早期（~33s ≈ 预热后）+ 跨轮 ±0.3s 重现 → 状态积累/确定性触发；中段（137s）→ 压力/内存爬坡；恢复阶段 → 运行态 vs 重放态分歧。
