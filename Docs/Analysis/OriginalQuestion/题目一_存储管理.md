> **题目种类**：内核代码填充  
> **推荐知识点**：存储管理的基本原理、文件存储组织、记录存储组织、缓冲区管理

## 题目描述

在大赛提供的代码框架的基础上，提供相关接口的实现，完成指定功能。本题目包含若干子任务，每个任务对应不同的测试点，只有通过相应测试点才可以获得相应的分数。

- 测试代码会调用指定接口来进行测试，参赛队伍**不能修改已有的接口**，也不能删除已有的数据结构及数据结构中的变量，但是可以增添新的接口、数据结构、变量。
- 大赛提供了项目结构文档来帮助参赛队伍理解代码框架，同时在代码注释中，也对数据结构及接口进行了说明，参赛队伍可以通过阅读代码注释来辅助理解代码框架。

## 1. 磁盘管理器

在本任务中，参赛队伍需要实现磁盘管理器 `DiskManager` 的相关接口，磁盘管理器负责文件操作、读写页面等。

需要阅读的文件：`src/errors.h`、`src/storage/disk_manager.h`、`src/storage/disk_manager.cpp`、`src/common/config.h`

### 需要实现的接口

| 接口 | 功能说明 |
|------|---------|
| `void DiskManager::create_file(const std::string &path)` | 创建文件，文件名为 `path` 指定的文件名 |
| `void DiskManager::open_file(const std::string &path)` | 打开 `path` 指定的文件 |
| `void DiskManager::close_file(const std::string &path)` | 关闭 `path` 指定的文件 |
| `void DiskManager::destroy_file(const std::string &path)` | 删除 `path` 指定的文件 |
| `void DiskManager::write_page(int fd, page_id_t page_no, const char *offset, int num_bytes)` | 在文件的指定页面写入指定长度的数据，从指定页面的起始位置开始写入 |
| `void DiskManager::read_page(int fd, page_id_t page_no, char *offset, int num_bytes)` | 从文件的指定页面读取指定长度的数据，从指定页面的起始位置开始读取 |

## 2. 缓冲池管理器

在本任务中，参赛队伍需要实现缓冲池管理器 `BufferPoolManager` 和缓冲池替换策略 `Replacer` 相关的接口。

需要阅读的文件夹：`src/storage`、`src/replacer`

### 2.1 LRUReplacer

实现 `Replacer` 的子类 `LRUReplacer`，需要实现的接口：

| 接口 | 功能说明 |
|------|---------|
| `bool LRUReplacer::victim(frame_id_t* frame_id)` | 选择并淘汰缓冲池中一个页面。成功返回 `true`，被淘汰的页面所在帧由 `frame_id` 返回 |
| `void LRUReplacer::pin(frame_id_t frame_id)` | 固定住一个帧中的页面，代表该页面正在使用，不可被换出 |
| `void LRUReplacer::unpin(frame_id_t frame_id)` | 取消固定一个帧中的页面，使用完毕时调用 |

### 2.2 BufferPoolManager

需要实现的接口：

| 接口 | 功能说明 |
|------|---------|
| `Page *BufferPoolManager::new_page(PageId *page_id)` | 在缓冲池中申请创建一个新页面。成功返回指向该页面的指针，同时通过 `page_id` 返回新建页面的编号 |
| `Page *BufferPoolManager::fetch_page(PageId page_id)` | 获取缓冲池中的指定页面 |
| `bool BufferPoolManager::find_victim_page(frame_id_t *frame_id)` | 寻找需要淘汰的页面。成功返回 `true`，需要调用 `LRUReplacer::victim` |
| `void BufferPoolManager::update_page(Page *page, PageId new_page_id, frame_id_t new_frame_id)` | 将指定帧中的原有页面刷入磁盘，更新页表，建立新页面和该帧的映射 |
| `bool BufferPoolManager::unpin_page(PageId page_id, bool is_dirty)` | 取消对页面的固定。所有操作都完成后，需要在 Replacer 中调用 `unpin` |
| `bool BufferPoolManager::delete_page(PageId page_id)` | 在缓冲池中删除指定页面，将该页面所在的帧置为空闲帧。如果页面正被使用，则不能删除 |
| `bool BufferPoolManager::flush_page(PageId page_id)` | 强制刷新缓冲池中的指定页面到磁盘，无论该页是否正在被使用或为脏页 |
| `void BufferPoolManager::flush_all_pages(int fd)` | 将指定文件中存在于缓冲池的所有页面都刷新到磁盘 |

> **提示**：在缓冲池中淘汰某个脏页时，需要将脏页写入磁盘。

## 3. 记录管理器

在本任务中，参赛队伍需要填充记录管理器涉及的 `RmFileHandle` 类和 `RmScan` 类。

需要阅读的文件夹：`src/record`

### 3.1 RmFileHandle

| 接口 | 功能说明 |
|------|---------|
| `std::unique_ptr<RmRecord> get_record(const Rid &rid, Context *context) const` | 获取表中某一条指定位置的记录，每条记录由 `Rid` 唯一标识 |
| `Rid insert_record(char *buf, Context *context)` | 向表中插入一条新记录，需要选择一个空闲位置插入并同步更新表的元数据信息 |
| `void insert_record(const Rid &rid, char *buf)` | 向表中的指定位置插入一条记录，主要用于事务的回滚和系统故障恢复 |
| `void delete_record(const Rid &rid, Context *context)` | 删除表中指定位置的记录 |
| `void update_record(const Rid &rid, char *buf, Context *context)` | 把表中指定位置的记录更新为新的值 |

### 3.2 RmScan

| 接口 | 功能说明 |
|------|---------|
| `RmScan(const RmFileHandle *file_handle)` | 构造函数，初始化相关成员变量 |
| `void next() override` | 找到表文件中下一个存放了合法记录的位置 |
| `bool is_end() const override` | 判断是否已经扫描到文件的末尾位置 |
