## 题目描述

本题目要求实现聚合函数与分组统计。

- **聚合函数**：对一组值进行计算并返回单一的值，通过使用 SQL 聚合函数，可以确定数值集合的各种统计值。
- **分组统计**：将查询结果按照 1 个或者多个字段进行分组，字段值相同的为同一组。

### 要求

| 功能 | 说明 |
|------|------|
| `COUNT(expr)` | `expr` 可以是列名或 `"*"`。`count(*)` 统计元组个数，`count(列名)` 统计一列中值的个数。支持 int、float、char 类型 |
| `MAX(expr)` | 返回一列中的最大值。支持 int、float 类型 |
| `MIN(expr)` | 返回一列中的最小值。支持 int、float 类型 |
| `SUM(expr)` | 返回数值列的总数。支持 int、float 类型 |
| `AVG(expr)` | 返回一列中的平均值。支持 int、float 类型 |
| `GROUP BY / HAVING` | `group by` 根据一个或多个列对结果集进行分组，`having` 对每一个分组按条件进行过滤。支持 int、float、char 类型 |
| `ORDER BY / LIMIT` | `order by` 对最终结果按照一个或多个列进行排序，可指定升序 `ASC` 或降序 `DESC`，默认采用 `ASC`。`limit` 限制查询结果的数量 |

### 测试点 3：健壮性测试

```sql
create table grade (course char(20),id int,score float);
insert into grade values('DataStructure',1,95);
insert into grade values('DataStructure',2,93.5);
insert into grade values('DataStructure',3,94.5);
insert into grade values('ComputerNetworks',1,99);
insert into grade values('ComputerNetworks',2,88.5);
insert into grade values('ComputerNetworks',3,92.5);
-- SELECT 列表中不能出现没有在 GROUP BY 子句中的非聚集列
select id, score from grade group by course;
-- WHERE 子句中不能用聚集函数作为条件表达式
select id, MAX(score) as max_score from grade where MAX(score) > 90 group by id;
```

