## 一、事务调用链

### 1.1 隐式事务（单语句自动）

```
client_handler()
  ├─→ SetTransaction(&txn_id, context)
  │     └─⇒ if (无活跃事务)
  │           └─→ txn_mgr_->begin(nullptr, log_mgr)          ✅ 题八
  │                 ├─→ 新建 Transaction(txn_id)
  │                 ├─→ txn_map[txn_id] = txn
  │                 └─→ 写 BeginLogRecord（可选）
  │
  ├─→ ... 执行 SQL ...
  │
  └─⇒ if (!txn_mode)                                        非显式事务模式
        └─→ txn_mgr_->commit(txn, log_mgr)                  ✅
              ├─→ 物化 MVCC / 写 Commit 日志
              ├─→ **S3：先 unlock_all，再 wait_for_persist** ✅
              │     └─→ log_mgr 组提交 flush_worker          ✅
              │           └─→ disk_manager_->write_log(...)  ✅（P1：pwrite+预分配）
              └─→ state = COMMITTED
```

### 1.2 显式事务（BEGIN / COMMIT / ABORT）

```
client_handler()
  └─→ portal.run() → PORTAL_CMD_UTILITY
        └─→ ql->run_cmd_utility(plan, txn_id, context)        🔧
              │
              ├─⇒ T_Transaction_begin
              │     └─→ context->txn_->set_txn_mode(true)     开启显式事务模式
              │
              ├─⇒ T_Transaction_commit
              │     └─→ txn_mgr_->commit(txn, log_mgr)        ✅ 题八
              │
              ├─⇒ T_Transaction_abort / T_Transaction_rollback
              │     └─→ txn_mgr_->abort(txn, log_mgr)         ✅ 题八/九
              │           ├─⇒ 题八（无并发）
              │           │     ├─→ 逆序遍历 write_set_
              │           │     │     Insert→Delete / Delete→Insert / Update→恢复旧值
              │           │     ├─→ 释放锁
              │           │     └─→ 写 AbortLog
              │           │
              │           └─⇒ 题九（MVCC + SSI）
              │                 ├─→ 清理 undo_logs_ 和 version_info_ 中的版本链
              │                 ├─→ state = ABORTED
              │                 └─→ 从 txn_map 移除
              │                 【不使用 write_set_ 逆序遍历回滚】
              │
              └─⇒ T_SetTransactionIsolationLevel
                    └─→ 设置隔离级别（SI / SERIALIZABLE）
```

### 1.3 异常触发 abort

```
client_handler()
  └─→ catch (TransactionAbortException &e)
        └─→ txn_mgr_->abort(txn, log_mgr)                     ✅ 题九 SSI 危险结构触发
              └─→ 向客户端发送 "abort\n"
```

## 二、MVCC + SSI 调用链（题目九）

### 2.1 SELECT 可见性判断

```
SeqScanExecutor::Next() / IndexScanExecutor::Next()
  ├─→ fh_->get_record(rid)                                   ✅ 题一
  ├─→ 读取 TupleMeta（ts_, is_deleted_）                      rm_defs.h ✅
  │
  ├─⇒ 可见性判断
  │     ├─→ if (TupleMeta.ts_ <= txn->get_start_ts())        当前事务开始后已提交
  │     │     └─→ 可见（返回记录）
  │     │
  │     └─→ else                                             版本太新，追溯 undo 链
  │           └─→ ReconstructTuple(rid, txn)                 ✅ execution_common.h 题九
  │                 ├─→ txn_mgr->GetUndoLink(rid)            ✅ transaction_manager.cpp
  │                 ├─⤷ while (UndoLink.IsValid())
  │                 │     ├─→ txn_mgr->GetUndoLog(link)      ✅
  │                 │     ├─→ if (undo_log.ts_ <= txn->start_ts_)
  │                 │     │     └─→ 找到可见版本
  ���                 │     │     └─→ 按 modified_fields_ 重建元组
  │                 │     └─→ else
  │                 │           └─→ link = undo_log.prev_version_   继续追溯
  │                 └─→ 返回重建后的 RmRecord
  │
  └─⇒ SSI 读集合保存
        ├─→ 记录 rid 到读集合
        ├─→ 记录扫描条件到谓词读集合
        └─→ 检查不可见写入，建立 rw 反依赖
              └─⇒ 若形成危险结构 → abort 当前事务
```

### 2.2 DML 写写冲突检测

```
UpdateExecutor::Next() / DeleteExecutor::Next() / InsertExecutor::Next()
  ├─→ 读取目标记录的 TupleMeta
  ├─⇒ if (TupleMeta.ts_ > txn->get_start_ts() && 写入者是另一活跃事务)
  │     └─→ 写写冲突（Write-Write Conflict）
  │     └─→ 应 abort 当前事务
  │
  └─→ 正常写入流程
        ├─→ 修改记录
        ├─→ 写 UndoLog（保存旧版本）
        ├─→ 更新 version_info_ 中的 UndoLink
        └─→ SSI 检测：与其他事务读集合比较，建立 rw 反依赖
              └─⇒ 若形成危险结构 → abort 当前事务
```

### 2.3 SSI 危险结构检测

```
每次新增 rw 反依赖后（SELECT 发现不可见写入，或 DML 发现影响其他事务读）
  └─→ 检测危险结构
        ├─→ 是否存在 Tin ->rw Tpivot 且 Tpivot ->rw Tout
        ├─⇒ 满足 Tin == Tout  【循环】
        │     或 Tout 提交早于 Tin  【连续】
        └─⇒ 若形成
              └─→ abort(新增该依赖的当前语句所在事务)
              └─→ 向客户端返回 "abort\n"
```

### 2.4 Watermark 与垃圾回收

```
Watermark::AddTxn(read_ts)                                   ✅ 题九
  └─→ current_reads_[read_ts]++
  └─⇒ if (read_ts < watermark_) watermark_ = read_ts

Watermark::RemoveTxn(read_ts)                                ✅ 题九
  └─→ current_reads_[read_ts]--
  └─→ if (降为 0) 删除
  └─→ watermark_ = current_reads_ 中最小 read_ts

TransactionManager::GarbageCollection()                      ✅ 题九
  └─⤷ 遍历所有页面版本链
        └─⇒ if (版本 ts < watermark_ && 版本已提交)
              └─→ 删除该旧版本
```

## 三、WAL 与日志调用链

### 3.1 日志写入（DML 过程中）

```
InsertExecutor::Next() / UpdateExecutor::Next() / DeleteExecutor::Next()
  │
  ├─→ 构造 LogRecord
  │     ├─⇒ InsertLogRecord(txn_id, insert_value, rid, table_name)   🔧（已有实现）
  │     ├─⇒ UpdateLogRecord(...)                                      ✅ 空壳，题十需实现
  │     └─⇒ DeleteLogRecord(...)                                      ✅ 空壳，题十需实现
  │
  └─→ log_mgr->add_log_to_buffer(log_record)                         ✅ 题十
        ├─→ global_lsn_++  分配 LSN
        ├─→ log_record->lsn_ = lsn
        ├─→ log_record->serialize(log_buffer_.buffer_ + offset)
        ├─→ log_buffer_.offset_ += log_record->log_tot_len_
        ├─⇒ if (log_buffer_.is_full(append_size))
        │     └─→ flush_log_to_disk()                                ✅
        └─→ 返回 lsn
```

### 3.2 日志刷盘

```
LogManager::flush_log_to_disk()                                ✅ 题十
  ├─→ disk_manager_->write_log(log_buffer_.buffer_, log_buffer_.offset_)
  │     ├─→ 若 log_fd_ == -1 则先 open_file(LOG_FILE_NAME)
  │     ├─→ lseek(log_fd_, 0, SEEK_END)
  │     └─→ write(log_fd_, data, size)
  ├─→ log_buffer_.offset_ = 0
  └─→ persist_lsn_ = 最后一条日志的 LSN
```

### 3.3 Commit / Abort 时强制刷日志

```
TransactionManager::commit(txn, log_mgr) / abort(txn, log_mgr)  ✅
  ├─→ 写 CommitLogRecord / AbortLogRecord                        ✅ 空壳，题十需实现
  ├─→ log_mgr->add_log_to_buffer(log_record)
  └─→ log_mgr->flush_log_to_disk()                               【force-at-commit】
```

### 3.4 页面刷盘的 WAL 检查

```
BufferPoolManager::flush_page(page_id)                         ✅ 题一
  ├─→ 页表查找 frame_id
  ├─⇒ 题十 WAL 检查
  │     └─→ 确保 page->get_page_lsn() <= persist_lsn_         【page_lsn 在前 4 字节】
  ├─→ disk_manager_->write_page(...)
  └─→ is_dirty_ = false
```

## 四、恢复调用链

```
rmdb.cpp::main()
  ├─→ sm_manager->open_db(db_name)                             ✅ 题二
  │
  ├─→ recovery->analyze()                                      ✅ 题十
  │     ├─→ 扫描日志文件（从开头或最后一个 checkpoint）
  │     ├─→ 遇到 BeginLog   → ATT[txn_id] = lsn
  │     ├─→ 遇到 CommitLog  → ATT 删除 txn_id
  │     └─→ 遇到 Update/Insert/Delete → DPT[page_id] = min(DPT[page_id], lsn)
  │     └─→ 返回：ATT（活跃事务表）+ DPT（脏页表）
  │
  ├─→ recovery->redo()                                         ✅ 题十
  │     ├─→ 从 DPT 中最小 rec_lsn 开始扫描日志
  │     ├─⤷ for (每条日志)
  │     │     ├─→ 若 page 不在内存 → fetch_page()
  │     │     └─⇒ if (page_lsn < log_lsn)
  │     │           ├─→ 重做该日志操作
  │     │           └─→ page->set_page_lsn(log_lsn)
  │     └─→ 【不关注事务是否提交，只要是写操作就重做】
  │
  ├─→ recovery->undo()                                         ✅ 题十
  │     ├─→ 遍历 ATT 中所有未提交事务
  │     ├─⤷ for (每个未提交事务)
  │     │     ├─→ 按 prev_lsn_ 链逆序遍历该事务日志
  │     │     └─→ 对每个写操作执行反向操作：
  │     │           Update → 写回 before-image
  │     │           Insert → Delete
  │     │           Delete → Insert
  │     └─→ 【从后往前 UNDO，直到遇到 BeginLog】
  │
  └─→ start_server()                                           ✅
```

## 六、事务与恢复速查表

| 操作 | 入口 | 核心中间节点 | 最终落点 |
|------|------|-------------|---------|
| **事务 begin** | `SetTransaction` | `TransactionManager::begin` | `txn_map[txn_id] = txn` |
| **事务 commit** | `run_cmd_utility` / 隐式 | `commit → flush_log_to_disk` | `state = COMMITTED` |
| **事务 abort** | `run_cmd_utility` / 异常 | `abort → 清理资源 → flush_log_to_disk` | `state = ABORTED` |
| **MVCC 可见性判断** | `get_record` | `TupleMeta.ts_` | ≤ start_ts 则可见 |
| **MVCC 版本追溯** | `ReconstructTuple` | `GetUndoLink → GetUndoLog` | 返回重建的 `RmRecord` |
| **SSI 危险结构** | SELECT / DML 执行时 | 读集合比较 → rw 反依赖 | 形成则 abort 当前事务 |
| **写写冲突** | DML 执行时 | `TupleMeta.ts_` 比较 | 冲突则 abort |
| **写日志** | `add_log_to_buffer` | `global_lsn++ → serialize → buffer` | 返回 LSN |
| **刷日志** | `flush_log_to_disk` | `write_log` | `persist_lsn_` 更新 |
| **页面刷盘 WAL** | `flush_page` | `page_lsn <= persist_lsn` 检查 | `write_page` |
| **恢复 analyze** | `main()` | 扫描日志 → 建 ATT + DPT | — |
| **恢复 redo** | `main()` | 按 DPT 最小 lsn 重做 | — |
| **恢复 undo** | `main()` | 按 ATT 逆序 UNDO | — |
| **静态检查点** | `create static_checkpoint` | `flush_all_pages → flush_log_to_disk` | 写 CheckpointLog |
