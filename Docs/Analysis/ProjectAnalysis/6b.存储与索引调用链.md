## 一、缓冲池调用链

### 1.1 页面命中（Hot Path）

```
BufferPoolManager::fetch_page(PageId page_id)                ✅
  ├─→ 分片页表 shards_[].page_table_ 查找
  │     └─⇒ 命中
  │           ├─→ pin_count_++
  │           ├─→ replacer_->Pin(frame_id)
  │           └─→ 返回 &pages_[frame_id]
  │
  └─⇒ 未命中
        ├─→ find_victim_page(&frame_id)                      ✅
        │     ├─⇒ if (!shard.free_frames_.empty())           // S6：分片空闲帧
        │     │     └─→ 从 free_frames_ 取 frame_id
        │     └─⇒ else
        │           └─→ replacer_->Victim(&frame_id)         ✅
        │
        ├─⇒ if (pages_[frame_id].is_dirty())                 victim 是脏页
        │     └─→ update_page(...) 刷脏                      ✅
        │
        ├─→ disk_manager_->read_page(...)                    ✅
        ├─→ 建立分片页表映射
        ├─→ pin_count_ = 1
        └─→ 返回 Page*
```

### 1.2 页面释放

```
BufferPoolManager::unpin_page(PageId page_id, bool is_dirty)  ✅ 题一
  ├─→ 页表查找 frame_id
  ├─→ pin_count_--
  ├─⇒ if (pin_count_ == 0)
  │     └─→ replacer_->Unpin(frame_id)                      ✅ 题一
  └─⇒ if (is_dirty) is_dirty_ = true
```

### 1.3 刷盘（WAL 语义）

```
BufferPoolManager::flush_page(PageId page_id)                ✅ 题一
  ├─→ 页表查找 frame_id
  ├─⇒ 题十 WAL 检查
  │     └─→ 确保 page_lsn_ <= persist_lsn_                 log_manager.h
  ├─→ disk_manager_->write_page(fd, page_no, data, PAGE_SIZE)  ✅ 题一
  └─→ is_dirty_ = false

BufferPoolManager::flush_all_pages(int fd)                   ✅ 题一
  └─⤷ 遍历所有帧
        └─⇒ if (page.fd == fd && is_dirty)
              └─→ flush_page(page_id)
```

## 二、记录层调用链

### 2.1 插入记录

```
RmFileHandle::insert_record(buf, context)                   ✅ 题一
  ├─→ create_page_handle()                                  ✅
  │     ├─⇒ if (file_hdr_.first_free_page_no != -1)
  │     │     └─→ 复用空闲页 → fetch_page_handle(page_no)
  │     └─⇒ else
  │           └─→ create_new_page_handle()                  ✅
  │                 ├─→ buffer_pool_manager_->new_page()    ✅
  │                 ├─→ 初始化 page_hdr（num_records=0, next_free=-1）
  │                 └─→ bitmap 清零
  │
  ├─→ bitmap 找第一个 0 位 → slot_no
  ├─→ memcpy 写入 slot
  ├─→ bitmap 置 1
  ├─→ page_hdr.num_records++
  ├─⇒ if (页面变满)
  │     └─→ 更新 file_hdr_.first_free_page_no 指向下一个空闲页
  ├─→ BufferPoolManager::unpin_page(..., true)               标记 dirty
  └─→ 返回 Rid{page_no, slot_no}
```

### 2.2 删除记录

```
RmFileHandle::delete_record(rid, context)                   ✅ 题一
  ├─→ fetch_page_handle(rid.page_no)                        ✅
  ├─→ bitmap 对应位清 0
  ├─→ page_hdr.num_records--
  ├─⇒ if (页面从满变未满)
  │     └─→ release_page_handle(page_handle)                ✅
  │           ├─→ page_hdr.next_free_page_no = file_hdr_.first_free_page_no
  │           └─→ file_hdr_.first_free_page_no = page_no
  ├─→ BufferPoolManager::unpin_page(..., true)               标记 dirty
  └─→ return
```

### 2.3 更新记录

```
RmFileHandle::update_record(rid, buf, context)              ✅ 题一
  ├─→ fetch_page_handle(rid.page_no)                        ✅
  ├─→ memcpy 覆盖 slot
  ├─→ BufferPoolManager::unpin_page(..., true)               标记 dirty
  └─→ return
```

### 2.4 获取记录

```
RmFileHandle::get_record(rid, context)                      ✅ 题一
  ├─→ fetch_page_handle(rid.page_no)                        ✅
  ├─→ 定位 slot → memcpy 构造 RmRecord
  ├─→ BufferPoolManager::unpin_page(...)                     注意：不标记 dirty
  └─→ 返回 RmRecord
```

### 2.5 全表扫描

```
RmScan::RmScan(file_handle)                                 ✅ 题一
  └─→ 初始化 rid_ = {page_no=1, slot_no=0}                 【page 0 是文件头】

RmScan::next()                                              ✅ 题一
  ├─→ slot_no++，在当前页 bitmap 找下一个 1 位
  ├─⇒ if (当前页扫完)
  │     └─→ page_no++，跳到下一页
  │     └─→ 在新页 bitmap 找第一个 1 位
  └─→ 直到找到有效记录或到达文件末尾

RmScan::is_end()                                            ✅ 题一
  └─→ return (page_no >= file_hdr_.num_pages)
```

## 三、B+ 树索引调用链

### 3.1 插入条目

```
IxIndexHandle::insert_entry(key, value, txn, inserted?)     ✅ 题三
  ├─→ find_leaf_page(key, INSERT, txn)                      ✅
  │     ├─→ 从 root_page_ 开始
  │     ├─⤷ while (非叶子)
  │     │     └─→ IxNodeHandle::internal_lookup(key)        ✅
  │     │           └─→ 遍历 keys 找孩子区间 → 返回 child page_no
  │     │     └─→ fetch_node(child_page_no) → 继续向下
  │     └─→ 返回 (leaf_node, root_is_latched)
  │
  ├─→ IxNodeHandle::insert(key, value)                      ✅
  │     ├─→ lower_bound(key) 找插入位置
  │     ├─⇒ if (key 已存在) return;                        【唯一索引，不覆盖原 RID】
  │     └─→ insert_pair(pos, key, rid)
  │
  ├─⇒ if (leaf.size > max_size - 1)                        叶子满，分裂
  │     ├─→ split(leaf)                                     ✅
  │     │     ├─→ create_node() 新节点
  │     │     ├─→ 后半部分 key/rid 移到新节点
  │     │     ├─→ 维护叶子双向链表（prev/next）
  │     │     └─→ 返回 new_node
  │     └─→ insert_into_parent(old, key, new, txn)          ✅
  │           ├─⇒ if (old 是根)
  │           │     └─→ create_node() 新建根
  │           │     └─→ 根插入 (key, new.page_no)
  │           │     └─→ update_root_page_no(new_root)
  │           └─⇒ else
  │                 └─→ fetch_node(parent)
  │                 └─→ parent.insert_pair(key, new.page_no)
  │                 └─⇒ if (parent 满)
  │                       └─→ split(parent) → insert_into_parent(...) 递归
  │
  ├─→ inserted? = (本次是否真正插入)                       【CREATE INDEX 用于判重】
  └─→ unpin leaf page
```

### 3.2 删除条目

```
IxIndexHandle::delete_entry(key, txn)                       ✅ 题三
  ├─→ find_leaf_page(key, DELETE, txn)                      ✅
  ├─→ IxNodeHandle::remove(key)                             ✅
  │     ├─→ lower_bound(key) → 定位
  │     ├─⇒ if (存在) erase_pair(pos)
  │     └─→ 返回新 size
  │
  ├─⇒ if (leaf.size < min_size)                            下溢，合并或重分配
  │     └─→ coalesce_or_redistribute(leaf, txn)             ✅
  │           ├─⇒ if (leaf 是根)
  │           │     └─→ adjust_root(leaf)                   ✅
  │           └─⇒ else
  │                 ├─→ fetch_node(parent)
  │                 ├─→ find_child(leaf) 定位
  │                 ├─→ 取兄弟节点（优先前驱）
  │                 ├─⇒ if (node.size + neighbor.size >= 2*min_size)
  │                 │     └─→ redistribute(neighbor, node, parent, index)  ✅
  │                 └─⇒ else
  │                       └─→ coalesce(neighbor, node, parent, ...)        ✅
  │                             ├─→ 全部键值对移到 neighbor
  │                             ├─→ erase_leaf + release_node_handle
  │                             ├─→ parent 删除 node 的条目
  │                             └─⇒ if (parent 变空)
  │                                   └─→ 递归 adjust_root / coalesce_or_redistribute
  │
  └─→ unpin pages
```

### 3.3 范围扫描

```
IxIndexHandle::lower_bound(key)                             ✅ 题三
  ├─→ find_leaf_page(key, FIND)
  ├─→ IxNodeHandle::lower_bound(key)                        ✅
  │     └─→ 节点内找第一个 ≥ key 的索引
  └─→ 返回 Iid{page_no, slot_no}

IxIndexHandle::upper_bound(key)                             ✅ 题三
  ├─→ find_leaf_page(key, FIND)
  ├─→ IxNodeHandle::upper_bound(key)                        ✅
  │     └─→ 节点内找第一个 > key 的索引
  └─→ 返回 Iid{page_no, slot_no}

IxScan::next()                                              ✅
  ├─→ slot_no++
  ├─⇒ if (到页尾且非最后叶子)
  │     └─→ 跳到 next_leaf 的 slot 0
  └─→ return

IxScan::is_end()                                            ✅
  └─→ return (iid_ == end_)
```

## 四、CREATE INDEX 调用链

```
client_handler()
  └─→ portal.run() → PORTAL_MULTI_QUERY
        └─→ ql->run_mutli_query(plan, context)                🔧
              └─⇒ DDLPlan, tag == T_CreateIndex
                    └─→ sm_manager_->create_index(tab, cols, context)  ✅ 题三
                          │
                          ├─→ ix_manager_->create_index(...)  ✅ 创建临时索引文件
                          ├─→ auto ih = ix_manager_->open_index(...)
                          │
                          ├─→ 全表扫描现有数据
                          │     ├─⇒ 纯 INT 且总键长 ≤ 16：批量快路径
                          │     │     ├─→ 收集 (编码 key, Rid) 并排序
                          │     │     ├─→ adjacent_find 检测完整复合键重复
                          │     │     └─→ 无重复才 bulk_load()
                          │     └─⇒ 其他类型：通用路径
                          │           ├─→ RmScan 遍历并拼接完整 key
                          │           ├─→ ih->insert_entry(..., &inserted)
                          │           └─⇒ if (!inserted) 抛 DuplicateKeyError
                          │
                          ├─⇒ if (构建异常)
                          │     ├─→ close_index(ih)           释放缓存页并关闭 fd
                          │     ├─→ destroy_index(...)        删除临时 .idx
                          │     └─→ 重新抛出；表数据和元数据不变
                          │
                          ├─→ ihs_[index_name] = std::move(ih)  【成功后才注册】
                          ├─→ TabMeta.indexes 加入 IndexMeta    【成功后才注册】
                          ├─→ 重算/设置涉及列的 index 标记
                          └─→ flush_meta()                      持久化 db.meta
```

> **提交边界**：临时索引构建完成之前，`ihs_`、`TabMeta.indexes` 和列 `index` 标记均不得变化。重复键不能通过 `std::unique` 去重，也不能依赖 `IxNodeHandle::insert` 的“重复时不插入”行为静默成功。

### DROP INDEX

```
sm_manager_->drop_index(tab, cols, context)                  ✅
  ├─→ ix_manager_->close_index(...) + destroy_index(...)     ✅
  ├─→ 从 TabMeta.indexes 移除 IndexMeta
  ├─→ 从 ihs_ 移除索引句柄
  └─→ flush_meta()
```

## 五、存储与索引速查表

| 操作 | 入口 | 核心中间节点 | 最终落点 |
|------|------|-------------|---------|
| **缓冲池取页** | `fetch_page` | `find_victim_page → update_page → read_page` | 返回 `Page*`（调用者需 unpin） |
| **缓冲池释放** | `unpin_page` | `pin_count-- → replacer->Unpin` | — |
| **缓冲池刷页** | `flush_page` | WAL 检查 → `write_page` | `is_dirty = false` |
| **插入记录** | `insert_record` | `create_page_handle → bitmap → memcpy` | 返回 `Rid` |
| **删除记录** | `delete_record` | `fetch_page_handle → bitmap清0` | `release_page_handle`（若变未满） |
| **获取记录** | `get_record` | `fetch_page_handle → memcpy` | 返回 `RmRecord`（调用者 unpin） |
| **全表扫描** | `RmScan` | `next() → bitmap找1位` | `rid()` |
| **B+ 树插入** | `insert_entry` | `find_leaf_page → insert` | 可能 `split → insert_into_parent`；可返回 `inserted` 判重 |
| **B+ 树删除** | `delete_entry` | `find_leaf_page → remove` | 可能 `coalesce_or_redistribute` |
| **范围扫描** | `lower_bound` / `upper_bound` | `find_leaf_page → node.lower_bound` | 返回 `Iid` |
| **CREATE INDEX** | `create_index` | `创建临时文件 → 全表扫描/排序 → 完整键判重` | 成功 `flush_meta`；失败关闭并删除临时索引 |
| **DROP INDEX** | `drop_index` | `close_index + destroy_index` | `flush_meta` |
