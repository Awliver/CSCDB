### SSI 核心机制（内联在 begin/commit/abort 及 DML 执行路径中）

> 以下不是独立函数，而是需在 `transaction_manager.cpp` 及相关执行算子中内联实现的逻辑：

| 机制 | 触发时机 | 检测逻辑 |
|------|---------|---------|
| **读集合保存** | SELECT / IndexScan 执行时 | 记录当前事务读取的所有 RID（精确读集合）以及谓词读（扫描范围/查询条件） |
| **rw 反依赖建立（reader → writer）** | DML（INSERT/DELETE/UPDATE）执行时 | 将写操作影响的记录与其他 SER 事务保存的读信息比较；若满足其他事务读条件且该读事务快照不包含本次写入，则建立 `reader ->rw current_writer` |
| **rw 反依赖建立（current_reader → writer）** | SELECT 执行时 | 检查其他事务已产生但当前快照不可见的写入；若会改变 SELECT 结果，则建立 `current_reader ->rw writer` |
| **危险结构检测** | 每次新增 rw 反依赖后 | 检测是否存在 `Tin ->rw Tpivot` 且 `Tpivot ->rw Tout`，满足 `Tin == Tout` 或 `Tout` 提交早于 `Tin` |
| **事务 abort** | 检测到危险结构时 | 新增该依赖的**当前语句所在事务**立即 abort，向客户端返回 `abort\n` |
