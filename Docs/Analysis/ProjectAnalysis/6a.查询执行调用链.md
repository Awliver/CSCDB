## 一、SQL 主循环（所有语句的公共入口）

```
rmdb.cpp::client_handler(conn_fd)
  │
  ├─→ rmdb.cpp::SetTransaction(&txn_id, context)
  │     ├─→ txn_mgr_->get_transaction(*txn_id)               ✅
  │     └─⇒ txn_mgr_->begin(nullptr, log_mgr)               ✅
  │           【隐式事务：无活跃事务时自动 begin】
  │
  ├─→ try_fast_parse_sql(stmt)                               ✅ 热路径
  │     └─⇒ 失败则 yyparse()                                 ✅ 生成 ast::TreeNode
  │
  ├─→ analyze->do_analyze(parse_tree)                        ✅ 返回 Query 对象
  │
  ├─→ optimizer->plan_query(query, context)                  ✅ 返回 Plan 树
  │     └─→ planner.do_planner(query, context)
  │           ├─→ logical_optimization(query)                ✅ 题四
  │           ├─→ physical_optimization(query)               ✅
  │           └─→ 返回 shared_ptr<Plan>
  │
  ├─→ portal->start(plan, context)                           ✅ Plan → Executor 转换
  │     └─→ 返回 PortalStmt（含 Executor 算子树根节点）
  │
  ├─→ portal->run(portalStmt, ql, &txn_id, context)          ✅ 按 tag 分派
  │     ├─→ PORTAL_ONE_SELECT    → ql->select_from(...)      ✅
  │     ├─→ PORTAL_DML_WITHOUT_SELECT → ql->run_dml(...)     ✅
  │     ├─→ PORTAL_MULTI_QUERY   → ql->run_mutli_query(...)  ✅
  │     └─→ PORTAL_CMD_UTILITY   → ql->run_cmd_utility(...)  ✅
  │
  ├─→ portal->drop()                                         ✅
  │
  └─⇒ if (!txn_mode) txn_mgr_->commit(txn, log_mgr)         ✅ 单语句隐式事务自动 commit
```

## 二、SELECT 调用链

### 2.1 计划生成

```
planner.do_planner(query, context)                         🔧
  └─⇒ DMLPlan, tag == T_select
        ├─→ generate_select_plan(query, context)
        │     ├─→ logical_optimization(query)              ✅ 题四：谓词下推+投影下推
        │     ├─→ physical_optimization(query)
        │     │     └─→ make_one_rel(query)                🔧
        │     │           ├─→ 每表生成 ScanPlan（SeqScan / IndexScan）
        │     │           └─→ 构建 JoinPlan 树
        │     ├─→ generate_sort_plan(query, plan)          ✅
        │     └─→ 顶部包裹 ProjectionPlan
        └─→ 返回 DMLPlan(T_select, ProjectionPlan)

portal.start(plan, context)                                🔧
  └─⇒ DMLPlan, tag == T_select
        ├─→ dynamic_pointer_cast<ProjectionPlan>(subplan_)
        └─→ convert_plan_executor(ProjectionPlan, context)   🔧 递归转换
              │
              ├─⇒ ProjectionPlan
              │     └─→ ProjectionExecutor(
              │           convert_plan_executor(subplan_),   ⤷ 递归
              │           sel_cols_)
              │
              ├─⇒ ScanPlan, tag == T_SeqScan
              │     └─→ SeqScanExecutor(sm, tab_name, conds, context)
              │
              ├─⇒ ScanPlan, tag != T_SeqScan
              │     └─→ IndexScanExecutor(sm, tab_name, conds, index_cols, context)
              │
              ├─⇒ JoinPlan
              │     └─→ NestedLoopJoinExecutor(
              │           convert_plan_executor(left_),      ⤷ 递归
              │           convert_plan_executor(right_),     ⤷ 递归
              │           conds)
              │
              └─⇒ SortPlan
                    └─→ SortExecutor(
                          convert_plan_executor(subplan_),   ⤷ 递归
                          sel_col, is_desc)
```

### 2.2 执行与输出

```
ql->select_from(root_executor, sel_cols, context)          🔧
  │
  ├─⇒ if EXPLAIN ANALYZE
  │     └─→ 遍历算子树，统计并输出各节点 rows              ✅ 题四
  │
  └─⇒ 正常 SELECT
        ├─→ root_executor->beginTuple()                    ✅
        ├─⤷ for (; !root_executor->is_end(); root_executor->nextTuple())
        │     └─→ auto rec = root_executor->Next()          ✅
        │           │
        │           ├─⇒ ProjectionExecutor::Next()
        │           │     └─→ prev_->Next()                 调下层算子
        │           │     └─→ 按 sel_idxs_ 抽取列
        │           │
        │           ├─⇒ SeqScanExecutor::Next()
        │           │     └─→ 推进 RmScan，应用 fed_conds_
        │           │
        │           ├─⇒ IndexScanExecutor::Next()
        │           │     └─→ 推进 IxScan（范围扫描）       ✅
        │           │     └─→ fh_->get_record(rid)          ✅
        │           │
        │           ├─⇒ NestedLoopJoinExecutor::Next()
        │           │     └─→ 左表驱动，右表每次 beginTuple()
        │           │     └─→ 拼接左右记录
        │           │
        │           └─⇒ SortExecutor::Next()
        │                 └─→ 先收集全部记录排序，再逐条输出
        │
        ├─→ RecordPrinter::print_record(columns, context)    ✅
        │     └─→ 写入 context->data_send_ + output.txt
        │
        └─→ write(conn_fd, data_send, offset)                ✅ 返回客户端
```

## 三、INSERT 调用链

```
portal.start(plan, context)
  └─⇒ DMLPlan, tag == T_Insert
        └─→ InsertExecutor(sm, tab_name, values, context)

ql->run_dml(InsertExecutor)                                ✅
  └─→ InsertExecutor::Next()                                🔧
        │
        ├─→ RmRecord rec(record_size)
        │     └─→ 逐列 memcpy 构造 rec.data（Value → 字节）
        │
        ├─→ fh_->insert_record(rec.data, context->txn_)     ✅ 题一
        │     ├─→ create_page_handle() / fetch_page_handle()
        │     ├─→ BufferPoolManager::fetch_page()           ✅
        │     ├─→ bitmap 找空闲 slot → memcpy 写入
        │     ├─→ BufferPoolManager::unpin_page(..., true)   标记 dirty
        │     └─→ 返回 Rid
        │
        ├─⤷ for (每个索引)
        │     ├─→ 从 rec.data 提取索引列，拼接 key
        │     └─→ ih->insert_entry(key, rid, txn)           ✅ 题三 B+树插入
        │           ├─→ find_leaf_page(key)
        │           ├─→ IxNodeHandle::insert()
        │           └─⇒ 若 size > max_size - 1
        │                 ├─→ split()
        │                 └─→ insert_into_parent()
        │
        ├─⇒ 记录 write_set_（题八/九）
        │     └─→ context->txn_->write_set_->push_back(...)
        │
        └─→ return nullptr                                    执行完成

【隐式事务自动 commit】
txn_mgr_->commit(txn, log_mgr)                             ✅ 题八
  ├─→ 写 CommitLogRecord                                  ✅ 题十
  ├─→ log_mgr->flush_log_to_disk()                        ✅
  │     └─→ disk_manager_->write_log(...)                 ✅
  └─→ 释放锁 / 清理状态
```

## 四、UPDATE / DELETE 调用链

```
portal.start(plan, context)
  └─⇒ DMLPlan, tag == T_Update / T_Delete
        ├─→ convert_plan_executor(subplan_)                  先转换扫描算子
        ├─⤷ for (scan->beginTuple(); !scan->is_end(); scan->nextTuple())
        │     └─→ rids.push_back(scan->rid())                收集所有目标 RID
        │
        ├─⇒ T_Update
        │     └─→ UpdateExecutor(sm, tab, set_clauses, conds, rids, context)
        └─⇒ T_Delete
              └─→ DeleteExecutor(sm, tab, conds, rids, context)

ql->run_dml(UpdateExecutor / DeleteExecutor)               ✅
  ├─⇒ UpdateExecutor::Next()                               ✅
  │     ├─⤷ for (每个 rid)
  │     │     ├─→ fh_->get_record(rid)                     ✅
  │     │     ├─→ 按 set_clauses_ 修改字段
  │     │     ├─→ fh_->update_record(rid, new_rec, txn)    ✅
  │     │     ├─⇒ 若索引列被修改
  ��     │     │     ├─→ ih->delete_entry(old_key)          ✅
  │     │     │     └─→ ih->insert_entry(new_key, rid)     ✅
  │     │     └─→ 记录 write_set_
  │     └─→ return nullptr
  │
  └─⇒ DeleteExecutor::Next()                               ✅
        ├─⤷ for (每个 rid)
        │     ├─→ 删除所有索引条目（逐索引 delete_entry）    ✅
        │     ├─→ fh_->delete_record(rid, txn)              ✅
        │     └─→ 记录 write_set_
        └─→ return nullptr
```

## 五、查询执行速查表

| 操作 | 入口 | 核心中间节点 | 最终落点 |
|------|------|-------------|---------|
| **SQL 从 socket 到结果** | `client_handler` | `SetTransaction → analyze → plan → portal.start → portal.run` | `write(conn_fd)` |
| **SELECT 计划生成** | `do_planner` | `logical_optimization → make_one_rel → generate_select_plan` | `DMLPlan(T_select)` |
| **SELECT 执行** | `select_from` | `beginTuple → Next()`（递归穿透算子树） | `RecordPrinter::print_record` |
| **INSERT 记录** | `InsertExecutor::Next` | `RmFileHandle::insert_record` | 索引同步 + `write_set_` |
| **DELETE 记录** | `DeleteExecutor::Next` | 索引删除 → `delete_record` | `write_set_` |
| **UPDATE 记录** | `UpdateExecutor::Next` | `get_record → 修改 → update_record` | 索引同步 + `write_set_` |
