## 修改优先级提示（针对 AI 代码生成）

1. **题目一**是地基，**所有 `.cpp` 中的 `// Todo` 都必须填充**，否则上层无法运行。
2. **题目二**依赖题目一，先确保 `create_table` + `insert` + `select` 最小通路。
3. **题目三**依赖题目一和二，B+ 树代码量大且复杂，建议独立分支开发。
4. **题目八~十**涉及跨模块联动（Executor → Transaction → Log → Recovery），建议最后攻坚。
5. **不要修改已有接口签名**（题目一尤其严格）；**题目二~十可自由重构**。
