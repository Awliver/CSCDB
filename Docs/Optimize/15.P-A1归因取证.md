> **当前裁决（2026-08-03）**：实现、确定性回归和 W=5 取证已完成；两次 W=50 开启态原因分布因本机测试成本不可接受而**项目冻结**。未做的正式规模终验不记为通过或失败；P-A1 不作为交付门禁，也不据此宣称已确定异常 abort 根因。

## 1. 口径与实现闭环

| 项 | 当前实现 |
|----|------------|
| 事务结果 | `attempted` / `committed` / `business_rollback` / `abnormal_abort` / `error` 五项可完全对账 |
| 稳定原因 | `ACTIVE_WRITE_CONFLICT` / `STALE_SNAPSHOT_WRITE` / `SSI_DANGEROUS_STRUCTURE` / `WFG_DEADLOCK` / `BUFFER_POOL_PRESSURE` / `OTHER` |
| 服务端 | `stmt_id × op_index × reason`；attempt/abort/总耗时/平均耗时；5s 增量单行输出 |
| 客户端 | `stmt_id/failed_op` 映射事务族，输出窗口、总量、原因和 hotspot，JSON 持久化 |
| 关闭路径 | 未设置 `RMDB_STMT_STATS` 时不计时、不分配统计槽、不执行原子计数 |
| 协议 | 原因继续通过现有 diagnostic token 透传，Wire v3 帧布局和状态码不变 |

## 3. W=5 单变量 A/B

### 3.1 实验设计

- 数据：`local_w5` CSV 新建共同基底，9/9 表计数完全一致；基底经 kill-9 重启后二次校验，882.0 MiB。
- 每个样本从同一基底复制独立工作副本；固定 `c446377`、SI、16 客户端、PREPARE_SET+EXEC_BATCH、45/43/4/4/4 事务比和 seed 42。
- 窗口：每样本 10s 预热 + 45s 测量，每侧 5 个独立进程。
- 唯一变量：OFF 完全移除 `RMDB_STMT_STATS`；ON 设为 `1`。不使用 `RMDB_STMT_STATS=0`，因为当前服务端按“环境变量是否存在”判定开启。
- 顺序：P1 OFF→ON，P2 ON→OFF，P3 OFF→ON，P4 ON→OFF，P5 OFF→ON，用交替顺序降低时间漂移偏差。

原始 JSON 与日志保存在 `build/pa1_evidence_20260803/`（本地取证产物，不入 Git）。

**主口径裁决**：按 [§14](./14.决赛优化状态与实施计划.md) “每侧至少 5 个独立进程、比较 median”口径，开启态吞吐变化 **-0.041%**，满足 ±1% 的 W=5 门槛。

**噪声警告**：5 个配对比值的中位为 **-2.163%**，范围 **-6.084%～+3.021%**；两组均值变化约 -1.69%。因此该结果只能裁决“W=5 组中位未观察到 >1% 回退”，不能声称统计开销已在 W=50 上确定小于 1%。
