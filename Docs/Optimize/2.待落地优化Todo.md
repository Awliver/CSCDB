## 3. 每项固定验证流程

```bash
cd build && make rmdb -j$(nproc)
python3 tests/run_tests.py
python3 tests/local/consistency/run_consistency_regress.py

# 定向用例通过后，才跑趋势与决赛形：
python3 tests/local/run_oj_perf_test.py --mid --scale local  # W=5 同机趋势
python3 tests/local/run_oj_perf_test.py --finals
bash tests/local/pre_oj_submit.sh
```

性能上线门槛：W=50 形中位提升 ≥5%，或异常 abort 相对下降 ≥20%；p99 不得恶化 >10%，任一测量轮不得退化 >2%。完整口径见 [§14 §6](./14.决赛优化状态与实施计划.md#6-统一验证方案)。
