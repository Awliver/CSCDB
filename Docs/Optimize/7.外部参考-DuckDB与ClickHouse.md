## 2. S5（commit ~71–73%）

### DuckDB 可借

- `BufferedFileWriter` / `ChecksumWriter`：先攒内存再整块写 → `log_manager` / `disk_manager::write_log`
- **不借**：每 commit `Sync()`、checkpoint 跳过 WAL

### ClickHouse 可借

- `write_ahead_log_bytes_to_fsync` / `write_ahead_log_interval_ms_to_fsync`：**字节/时间阈值思想**（时间 `sleep_for` OJ 已证伪）
- `WriteBufferFromFileDescriptor::sync()`：`next()` 再 `fdatasync`（RMDB 已做）
- **不借**：`fsync_after_insert=false`、MergeTree 耐久模型

### 自研方向

见 [§4](./4.S5-WAL组提交深化.md)：字节积压 ≥ M 或等待者 ≥ N 触发刷盘，**不用固定 `sleep_for`**。
